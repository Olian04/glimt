# logviz

## WIP

Log visualizer

Reads structured logs on stdin or from selected files and renders the logs in a TUI. 
Default TUI is a table view of all logs, with optional additional visualizations, searching and filtering via hotkeys.

Take inspiration from:
- https://github.com/control-theory/gonzo
- https://github.com/Lifailon/lazyjournal
- https://github.com/jorgerojas26/lazysql
- https://github.com/charmbracelet/crush
